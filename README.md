# AI Document Intelligence System

An AI-powered document analysis application built using Python, Streamlit, and Google Gemini API.

## Features

- Upload PDF documents
- Extract text using PyMuPDF
- Ask questions about uploaded documents
- AI-powered contextual answers using Google Gemini
- Interactive Streamlit interface

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyMuPDF
- Git & GitHub

## Project Structure

```
app.py
utils/
    gemini_chat.py
    pdf_reader.py
    prompts.py
    vector_store.py
```
